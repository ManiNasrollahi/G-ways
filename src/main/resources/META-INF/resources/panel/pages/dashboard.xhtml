Read the route configuration report

The summary counts all saved routes, enabled routes, filters and policies, and routes without enabled predicates.

Each card shows a route's destination and priority. Its table includes every saved predicate, BEFORE/AFTER filter, rate limit, retry policy, and circuit breaker, including disabled entries. Configuration displays the saved JSON or policy values.

A rule is inactive when either it or its route is disabled. An enabled configuration does not confirm that a service is healthy or that a configuration was successfully published on every instance.

Use Refresh report after editing configuration. Request metrics, upstream health, and live circuit-breaker state are not measured by this report.
